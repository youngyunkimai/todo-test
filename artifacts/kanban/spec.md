## Overview
Trello 스타일의 칸반 Todo 앱. 3칼럼 보드에서 카드를 드래그&드롭으로 관리하고, 검색/필터/다크모드를 지원하며, 데이터를 localStorage에 저장한다.

## 시나리오

### 1. 카드 생성
[상황] 사용자가 칼럼의 '추가' 버튼을 클릭하고 제목을 입력하면
[동작] 해당 칼럼 하단에 새 카드가 추가된다

성공 기준:
- [ ] "To Do" 칼럼에서 '추가' 클릭 → 제목 "장보기" 입력 → "장보기" 카드가 "To Do" 칼럼에 표시
- [ ] 제목 미입력 상태에서 저장 시도 → "제목을 입력해주세요" 오류 메시지 표시

### 2. 카드 상세 보기 및 편집
[상황] 사용자가 카드를 클릭하면
[동작] 상세 다이얼로그가 열리고, 제목/설명/우선순위/태그/마감일/서브태스크를 편집할 수 있다

성공 기준:
- [ ] 카드 클릭 → 다이얼로그에 제목, 설명, 우선순위, 태그, 마감일, 서브태스크 필드 표시
- [ ] 제목을 "장보기"에서 "마트 장보기"로 수정 후 저장 → 보드에 "마트 장보기"로 표시
- [ ] 우선순위를 "High"로 변경 → 카드에 "High" 우선순위 배지 표시

### 3. 카드 삭제
[상황] 사용자가 카드 상세 다이얼로그에서 '삭제' 버튼을 클릭하면
[동작] 확인 후 카드가 보드에서 제거된다

성공 기준:
- [ ] 삭제 확인 → 해당 카드가 칼럼에서 사라짐, 칼럼 카드 수 1 감소
- [ ] 삭제 취소 → 카드가 그대로 유지

### 4. 서브태스크 관리
[상황] 사용자가 카드 상세에서 서브태스크를 추가하거나 체크하면
[동작] 서브태스크 목록이 업데이트되고 진행률이 표시된다

성공 기준:
- [ ] 서브태스크 "계란 사기" 추가 → 체크리스트에 "계란 사기" 항목 표시
- [ ] 서브태스크 2개 중 1개 체크 → "1/2" 진행률 표시
- [ ] 빈 서브태스크 추가 시도 → "내용을 입력해주세요" 오류 메시지 표시

### 5. 칼럼 간 드래그&드롭
[상황] 사용자가 카드를 다른 칼럼으로 드래그하면
[동작] 카드가 대상 칼럼으로 이동한다

성공 기준:
- [ ] "To Do" 카드를 "In Progress"로 드래그 → "To Do" 카드 수 1 감소, "In Progress" 카드 수 1 증가
- [ ] "In Progress" 카드를 "Done"으로 드래그 → "Done" 칼럼에 해당 카드 표시

### 6. 칼럼 내 순서 변경
[상황] 사용자가 같은 칼럼 내에서 카드를 드래그하여 순서를 변경하면
[동작] 카드 순서가 변경된다

성공 기준:
- [ ] "To Do" 칼럼에 카드 A, B, C 순서 → A를 C 아래로 드래그 → B, C, A 순서로 표시

### 7. 제목 검색
[상황] 사용자가 검색창에 키워드를 입력하면
[동작] 제목에 키워드가 포함된 카드만 표시된다

성공 기준:
- [ ] "장" 입력 → "장보기" 카드 표시, "회의" 카드 숨김
- [ ] 검색어 삭제 → 모든 카드 다시 표시

### 8. 우선순위 필터
[상황] 사용자가 우선순위 필터를 선택하면
[동작] 해당 우선순위의 카드만 표시된다

성공 기준:
- [ ] "High" 필터 선택 → High 우선순위 카드만 표시, Medium/Low 카드 숨김
- [ ] 필터 해제 → 모든 카드 표시

### 9. 태그 필터
[상황] 사용자가 태그 필터를 선택하면
[동작] 해당 태그가 있는 카드만 표시된다

성공 기준:
- [ ] "Bug" 태그 필터 선택 → Bug 태그가 있는 카드만 표시
- [ ] 복수 태그 선택 (Bug, Feature) → Bug 또는 Feature 태그가 있는 카드 표시 (OR 조건)

### 10. 다크모드 토글
[상황] 사용자가 다크모드 토글을 클릭하면
[동작] 앱 전체 테마가 라이트/다크로 전환된다

성공 기준:
- [ ] 라이트 모드에서 토글 클릭 → 다크 모드 적용 (dark 클래스 또는 data 속성)
- [ ] 다크 모드에서 토글 클릭 → 라이트 모드 복귀

### 11. localStorage 저장 및 복원
[상황] 사용자가 보드를 변경한 후 페이지를 새로고침하면
[동작] 이전 상태가 그대로 복원된다

성공 기준:
- [ ] 카드 추가 후 새로고침 → 추가한 카드가 그대로 표시
- [ ] 다크모드 설정 후 새로고침 → 다크모드 유지
- [ ] 카드를 다른 칼럼으로 이동 후 새로고침 → 이동한 칼럼에 카드 유지

### 12. 검색과 필터 동시 적용
[상황] 사용자가 검색어와 우선순위/태그 필터를 동시에 사용하면
[동작] 모든 조건을 AND로 만족하는 카드만 표시된다

성공 기준:
- [ ] 검색어 "장" + 우선순위 "High" → High이면서 제목에 "장"이 포함된 카드만 표시

### 13. 빈 칼럼으로 카드 드래그
[상황] 사용자가 카드를 카드가 0개인 칼럼으로 드래그하면
[동작] 해당 빈 칼럼에 카드가 추가된다

성공 기준:
- [ ] "In Progress" 카드 1개를 카드 0개인 "Done"으로 드래그 → "Done" 칼럼에 카드 1개 표시

### 14. 서브태스크 체크 해제
[상황] 사용자가 체크된 서브태스크를 다시 클릭하면
[동작] 체크가 해제되고 진행률이 감소한다

성공 기준:
- [ ] 서브태스크 2개 중 1개 체크 상태("1/2")에서 해제 → "0/2" 진행률 표시

### 15. 태그 필터 해제
[상황] 사용자가 적용된 태그 필터를 해제하면
[동작] 모든 카드가 다시 표시된다

성공 기준:
- [ ] "Bug" 태그 필터 적용 상태에서 해제 → 전체 카드 표시

## 범위

### 포함
- 3칼럼 칸반 보드 (To Do / In Progress / Done, 고정)
- 카드 CRUD (생성, 조회, 수정, 삭제)
- 카드 필드: 제목, 설명, 우선순위(High/Medium/Low), 사전 정의 태그, 마감일, 서브태스크
- 드래그&드롭 (칼럼 간 이동 + 칼럼 내 순서 변경)
- 제목 검색
- 우선순위/태그 필터
- 다크모드 토글
- localStorage 영속화

### 제외
- 칼럼 추가/삭제/이름 변경: 초기 버전에서는 고정 3칼럼으로 복잡도를 낮춤
- 사용자 인증/멀티유저: 로컬 전용 앱이므로 불필요
- 서버/DB 연동: localStorage만 사용
- 태그 자유 입력/관리: 사전 정의 태그만 지원하여 일관성 유지
- 서브태스크 순서 변경: 체크/언체크만 지원하여 구현 복잡도 축소
- 마감일 알림: 알림 시스템은 범위 밖

## 전제 조건
- Next.js + shadcn/ui 기반 프로젝트
- 드래그&드롭 라이브러리 사용 (e.g. @hello-pangea/dnd)
- 사전 정의 태그 목록: Bug, Feature, Design, Docs
